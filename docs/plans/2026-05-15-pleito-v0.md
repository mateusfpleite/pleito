# Pleito V0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Apply @superpowers:test-driven-development and @superpowers:testing-anti-patterns throughout (do NOT test "the LLM returns X" — test deterministic logic: parsing, validation, baseline precedence, gate conditions).

**Goal:** Web app onde a Stefany faz upload de um edital de licitação funerária e recebe um dashboard estruturado + rascunho de ofício, com verificação de vigência de normas à prova de falso-positivo.

**Architecture:** Hexagonal. `domain/` (tipos, schema Zod, ports — zero deps externas) ← `application/` (workflow que orquestra 7 componentes com 2 gates condicionais) ← `adapters/` (extractor, verifier, risk-analyst, drafter, pdf, repo) ← `app/` (Next.js). LLM atrás de ports, trocável por env var. Verifier 3-camadas: `data/norma-baseline.json` (determinístico) → web grounding (cauda) → contenção no Drafter.

**Tech Stack:** Next.js (App Router) · TypeScript · Vercel AI SDK + `@ai-sdk/google` (Gemini 2.5 Flash) · Zod · Prisma + Supabase Postgres · Vitest · Playwright (PDF render) · deploy Vercel.

**Reference (POC já validado, não reescrever do zero — portar):** `src/extract.ts` (extractor), `src/spike-verifier.ts` (verifier baseline+grounding), `src/schema.ts` (schema v2 → migrar v3), `data/norma-baseline.json` (pronto), `fixtures/` (corpus de validação).
