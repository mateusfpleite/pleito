# Pleito V0 Implementation Plan (rev. 3 — post 2 plan-reviews + matcher spike)

> **For Claude:** REQUIRED SUB-SKILL: superpowers:executing-plans / superpowers:subagent-driven-development. Apply @superpowers:test-driven-development and @superpowers:testing-anti-patterns. NEVER test "the LLM returned X". This rev. incorporates: the 10 fixes from the 1st review, the async/worker architecture, and the 7 blockers from the 2nd review (#1 matcher validated by a spike; #2 structural containment; #3 worker trigger+lock; #4 Tier0 sequencing; #5 fixtures/gold; #6 reuse coherence; #7 login).

**Goal:** A web app where Stefany uploads an edital and gets a dashboard + an ofício draft, vigência verification proof against false-positive AND false-negative, asynchronous processing, real-usage telemetry.

**Architecture:** Vercel/Next.js (UI, auth, upload→job, polling, export) ↔ Supabase (jobs/analyses/norma_cache/telemetry) ↔ worker container (Railway/Cloud Run scale-to-zero, Dockerfile poppler+chromium, woken by HTTP from /api/job, atomic claim) that runs the 7-component TS pipeline with no timeout. Hexagonal: domain (zero dep) ← application ← adapters ← {app, worker}.

**Reuse (corrected):** reuses **validated prompts + `data/norma-baseline.json` + schema**. `src/extract.ts`/`spike-verifier.ts`/`spike-matcher.ts` are CLI scripts — the **validated logic** (normalization proven in the spike-matcher; prompts; baseline precedence) is reused; the **I/O is rewritten** as adapters.

**Stack:** Next.js (App Router) · TS · Vercel AI SDK + `@ai-sdk/google` (Gemini 2.5 Flash) · Zod · Prisma + Supabase · Vitest · Docker (worker).

## Phase 9 — Tier 0 Gate [#2 structural, #4 correct sequencing: HERE, after the Drafter]

### Task 9.1: structural checarContencao
`eval/tier0.ts`+test. `checarContencao(analise)`: for each cited law, **compares `afirmacaoVigencia` (the Drafter's field) vs `statusVerificado`** — `revogada` without `statusVerificado=revogada` = a violation. **No regex in the primary gate.** Secondary alarm: a broad lexical scan (`revogad|perdeu vigência|não está mais em vigor|deixou de viger`) in the markdown — fires but `afirmacaoVigencia=nenhuma` → a violation (inconsistency). Baseline-consistency. Test: clean case→0; injected violation→>0; 5 revogação paraphrases caught by the secondary alarm. The `eval:tier0` script runs against `fixtures/gold/*.json` + generated analyses; exit≠0 if it violates. Commit `feat: gate Tier 0 estrutural (ship V0)`.

## Phase 12 — Asynchronous job [#3 trigger + lock]

### Task 12.1: /api/job (trigger) + worker atomic claim
`app/api/job/route.ts`, `app/api/status/[id]/route.ts`, `worker/index.ts`, `infrastructure/factories.ts`.
- `POST /api/job`: creates a pending Job; **does a `POST` to `config.WORKER_URL` (wakes the scale-to-zero container)**; returns the id. `runtime='nodejs'`, DATABASE_URL pooled.
- Worker: on receiving the trigger, **atomic claim** `UPDATE jobs SET status='running' WHERE id=(SELECT id FROM jobs WHERE status='pending' ORDER BY created_at FOR UPDATE SKIP LOCKED LIMIT 1) RETURNING *`; processes via `analyzeEdital`; writes; status done/erro. Direct Postgres connection.
- `GET /api/status/:id` reflects the state.
- Test: creates a job→trigger called (mock fetch); **concurrency: 2 simultaneous claims pick different jobs** (one gets null); status reflects. Commit. Step `pnpm test && pnpm eval:tier0`.
